## Our Project: *7th Hell*

*7th Hell* is a fast‑paced, top‑down action RPG set inside a surreal, shifting underworld. The player fights through seven layers of "personal hells," each representing a psychological theme. Combat is quick and responsive, environments morph dynamically, and each layer introduces new mechanics, enemies, and emotional tone.
